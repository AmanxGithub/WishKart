| Tool              | Container       |    Port | Purpose                  |
| ----------------- | --------------- | ------: | ------------------------ |
| **Kafka**         | `kafka`         | `29092` | Messaging                |
| **Kafka UI**      | `kafka-ui`      |  `8090` | Kafka visualization      |
| **Prometheus**    | `prometheus`    |  `9090` | Metrics collection       |
| **Grafana**       | `grafana`       |  `3000` | Metrics dashboards       |
| **Elasticsearch** | `elasticsearch` |  `9200` | Log storage/search       |
| **Logstash**      | `logstash`      |  `5000` | Log ingestion/processing |
| **Kibana**        | `kibana`        |  `5601` | Log search/visualization |
| **docker**        | `docker`        |  `6379` | caching                  |
